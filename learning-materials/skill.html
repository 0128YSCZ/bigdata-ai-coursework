Skill（技能/可复用能力）

AI 平台核心概念 生成日期：2026-09-05

1. 一句话定义

Skill 是对一类可复用任务的封装，包含明确的输入、执行流程、输出规范和自检标准，使 AI 助手能够在不同场景中稳定地重复完成同类工作。

个人理解

Skill 就像是给 AI 写的一份“岗位说明书”。它告诉 AI：这个任务是什么场景、需要哪些信息、按什么步骤做、输出成什么样、做完后怎么检查。把这类说明写成文件存起来，以后遇到同样的任务，AI 就能直接照做，不用每次都重新解释一遍。本次作业要求创建的“概念学习资料生成 Skill”就是一个典型例子。

2. 核心机制与组成

  • 元数据（Metadata）：Skill 的名称、描述、作者、标签等，方便检索和调用。
  • 适用场景：说明这个 Skill 解决什么问题、在什么情况下使用。
  • 输入定义：明确调用者需要提供哪些信息，比如概念名称、深度、侧重点。
  • 执行流程/生成步骤：把任务拆成若干步骤，规定先做什么、后做什么。
  • 输出结构：规定最终产物格式，例如 HTML 文件应包含哪些章节。
  • 自检清单：列出验收标准，确保输出质量稳定。
核心思想：Skill 把“一次性提示词”升级为“可复用模板”。它关注的不是某一次回答，而是让同类任务都能被稳定、规范地完成。

3. 具体应用场景

场景：本次作业中的“概念学习资料生成 Skill”。

老师在作业里要求：创建一个 Skill，并用它来学习 Agent、大模型上下文、Skill 三个概念。这个 Skill 的调用方式如下：

  1. 提供一个新概念（如“Transformer”）；
  2. Skill 会按照固定流程生成一份 HTML 学习资料；
  3. 资料包含定义、个人理解、核心机制、应用场景、易混淆边界和可核查来源；
  4. 生成后对照自检清单检查，人工修改完善。

以后学习其他课程概念时，只需换输入概念名称，就能复用同一套流程，避免每次都从零写提示词。

4. 易混淆问题与使用边界

  • Skill ≠ 单一提示词：提示词只是一段文本，Skill 是包含场景、输入、流程、输出、自检的完整规范。
  • Skill ≠ Agent：Skill 是 Agent 可调用的“能力模块”；Agent 是执行者，Skill 是它执行任务的依据之一。
  • 边界：Skill 不能替代人的判断。它负责规范流程，但生成内容仍需人工核查，尤其是资料来源、事实准确性和个人理解部分。
注意：不要把 Skill 写成只针对某一个概念的“死提示词”。好的 Skill 应该像函数一样可参数化，接收不同输入都能稳定输出。
