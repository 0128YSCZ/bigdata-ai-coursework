# 概念学习资料生成 Skill

## 一、适用场景

- 学习《大数据与人工智能》课程中的新概念（如 Agent、大模型上下文、Skill 等）。
- 需要把抽象概念整理成一份结构清晰、可复用、可在线浏览的学习资料。
- 希望每份资料都包含个人理解、机制拆解、应用场景、常见误区和可核查来源，便于复习和自查。

## 二、输入信息

调用本 Skill 时，只需提供一个新概念：

- `concept`：概念名称（中文或英文均可，例如 "Agent"、"大模型的上下文"、"Skill"）。
- `depth`（可选）：期望的解释深度，如 `入门级`、`进阶级`，默认 `入门级`。
- `focus`（可选）：希望侧重的方向，如 `原理`、`应用`、`与其他概念对比`，默认 `原理+应用`。

## 三、生成步骤

1. **明确概念定义**：用一句话给出概念的简洁定义，并用个人语言重新解释，避免照搬百科。
2. **拆解核心机制/组成**：列出 3–5 个核心要点，说明概念由哪些部分组成、如何运转。
3. **举一个具体应用场景**：结合课程或生活实例，说明这个概念在哪里被使用、解决了什么问题。
4. **指出易混淆问题或使用边界**：列出 2–3 个常见误区，或说明该概念与相近概念的区别。
5. **给出可核查的资料来源**：至少提供 2 个权威来源（官方文档、经典论文、教材章节、权威博客），并附上链接或引用信息。
6. **输出为 HTML**：将以上内容渲染成独立的 `concept.html` 文件，包含标题、目录、正文和来源列表。

## 四、输出结构

每次调用生成一个 HTML 文件，固定包含以下区块：

```html
<h1>概念名称</h1>
<section id="definition">
  <h2>1. 一句话定义</h2>
  <p>...</p>
  <h3>个人理解</h3>
  <p>...</p>
</section>
<section id="mechanism">
  <h2>2. 核心机制与组成</h2>
  <ul>...</ul>
</section>
<section id="scenario">
  <h2>3. 具体应用场景</h2>
  <p>...</p>
</section>
<section id="boundary">
  <h2>4. 易混淆问题与使用边界</h2>
  <ul>...</ul>
</section>
<section id="sources">
  <h2>5. 可核查的资料来源</h2>
  <ol>...</ol>
</section>
```

## 五、资料来源要求

- 优先使用官方文档、经典教材、权威论文或知名技术博客。
- 不得伪造链接；若链接可能失效，应注明原始出处和检索日期。
- 对于争议性定义，应给出多个来源并标注差异。

## 六、自检要求

生成完成后，请按以下清单检查：

- [ ] 定义是否准确、简洁？
- [ ] 是否有明确的“个人理解”而非纯复制？
- [ ] 核心机制是否列出 3 项以上？
- [ ] 应用场景是否具体、可理解？
- [ ] 是否指出至少 2 个易混淆点或边界？
- [ ] 是否有至少 2 个可核查来源？
- [ ] HTML 文件是否能在浏览器中正常打开、结构清晰？

## 七、调用示例

在 WorkBuddy 中，指向本仓库后，可这样调用：

> “调用 `.workbuddy/skills/concept-study-generator` Skill，为 `Agent` 生成学习资料。”

或手动按照本 Skill 的“生成步骤”与“输出结构”创建 `learning-materials/<concept>.html`。
